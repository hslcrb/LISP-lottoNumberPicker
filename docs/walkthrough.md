# 🍀 고급 CLI 로또 번호 추첨기 완성

모든 요청하신 기능을 통합한 완성형 로또 추첨 프로그램을 구현했습니다. 이제 단순한 번호 생성을 넘어 제약 조건 설정, 시뮬레이션, 색상 출력 등이 가능합니다.

## ✨ 주요 구현 기능

### 1. 시각적 경험 (ANSI Color)
번호 대역별로 실제 로또 공 색상과 유사한 색상을 적용했습니다.
- **1~10**: 노란색
- **11~20**: 파란색
- **21~30**: 빨간색
- **31~40**: 회색
- **41~45**: 초록색

### 2. 정밀한 제약 조건 설정
고정수(반드시 포함)와 제외수(절대 미포함)를 설정할 수 있습니다.
- 예: `./lotto.lisp --fixed "1,7" --exclude "13,44"`

### 3. 당첨 시뮬레이션
특정 당첨 번호를 입력하면, 생성된 번호들과 비교하여 등수(1~5등)를 자동으로 계산해 줍니다.
- 예: `./lotto.lisp -c 10 --simulate "1,2,3,4,5,6"`

### 4. 결과 저장 및 파일 출력
화면 출력과 동시에 텍스트 파일로 결과를 저장할 수 있습니다. 파일에는 ANSI 색상 코드 없이 깔끔한 텍스트만 저장됩니다.
- 예: `./lotto.lisp -s my_numbers.txt`

### 5. 대화형 모드 지원
인수 없이 실행하거나 `-i` 옵션을 사용하면 단계별 질문을 통해 설정을 진행할 수 있습니다.

## 🛠️ 사용 예시 명령어

```bash
# 1. 가장 화려한 실행 (5게임, 고정수 1, 당첨 확인, 파일 저장)
./lotto.lisp -c 5 -f 1 -m "1,12,23,34,44,45" -s result.txt

# 2. 제외수 설정 실행
./lotto.lisp --exclude "4,13,44"

# 3. 대화형 모드로 시작
./lotto.lisp -i
```

## 🧪 검증 결과
- **인수 파싱**: 쉼표와 공백 구분자 모두 완벽하게 처리합니다.
- **배포성**: 외부 라이브러리(UIOP 등) 의존성을 제거하여 `sbcl`만 설치되어 있다면 어디서든 바로 실행됩니다.
- **예외 처리**: 잘못된 숫자 입력이나 고정수가 너무 많은 경우 등에 대해 기본적인 방어 로직이 포함되어 있습니다.
