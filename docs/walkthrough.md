# 🧬 PolyLotto: 유기적 다중 언어 로또 생태계 완성

단일 스크립트였던 로또 생성기를 5가지 프로그래밍 언어가 각자의 역할을 수행하며 유기적으로 협력하는 **전문 소프트웨어 스위트**로 진화시켰습니다.

## 🏗️ 시스템 아키텍처: 언어별 역할 분담

각 언어는 인간의 장기에 비유될 수 있는 핵심적인 역할을 수행합니다.

| 언어 | 비유 | 역할 | 상세 내용 |
| :--- | :--- | :--- | :--- |
| **Lisp** | **두뇌 (Brain)** | 오케스트레이터 | 전체 시스템 제어 및 타 모듈 호출/데이터 중계 |
| **C** | **심장 (Heart)** | 난수 코어 | 고속 난수 생성 및 기초 데이터 스트림 공급 |
| **C++** | **몸통 (Body)** | 로직 엔진 | 데이터 필터링 및 JSON/XML 표준 포맷터 |
| **FORTRAN** | **이성 (Mind)** | 통계 분석 | 수치 해석 기반의 빈도 및 평균 분석 |
| **COBOL** | **목소리 (Voice)** | 리포터 | 기업용 비즈니스 양식의 공식 보고서 생성 |

## 🔗 데이터 파이프라인 (Organic Integration)

모든 모듈은 표준화된 데이터 스트림을 통해 유연하게 소통합니다.
1.  **C**에서 생성된 순수 숫자 데이터가 **C++**로 흘러가 포맷팅됩니다.
2.  동시에 **FORTRAN**이 해당 데이터를 가로채 복잡한 수학적 분석을 수행합니다.
3.  최종적으로 **COBOL**이 분석된 결과물을 공식적인 보고서 형태로 출력합니다.

## 🚀 실행 및 활용 방법

### 빌드 환경
통합 `Makefile`을 통해 모든 언어의 소스 코드를 한 번에 컴파일할 수 있습니다.
```bash
make all
```

### 실행 명령어
루트 폴더의 `lotto` 심볼릭 링크를 통해 전체 시스템을 구동합니다.
```bash
# 기본 실행 (텍스트 형태)
./lotto -c 5

# JSON 형식 출력 모드
./lotto -c 10 --json

# XML 형식 출력 모드
./lotto -c 5 --xml

# 대화형 모드
./lotto -i
```

## 📂 프로젝트 구조 (`src/`)
- `src/orchestrator/`: Lisp 메인 제어부
- `src/core/`: C 언어 순수 생성부
- `src/engine/`: C++ 로직 및 포맷 변환부
- `src/stats/`: FORTRAN 통계 분석부
- `src/reporter/`: COBOL 보고서 생성부

이제 단순한 장난감이 아닌, 컴퓨터 공학의 역사를 관통하는 여러 언어들이 하나로 뭉친 강력한 소프트웨어 생태계를 갖추게 되었습니다! 🍀
