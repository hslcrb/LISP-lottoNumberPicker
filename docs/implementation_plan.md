# PolyLotto: 차세대 다중 언어 로또 엔진 프로젝트 계획서

단순한 스크립트를 넘어, 역사와 전통의 언어(COBOL, FORTRAN)부터 현대적인 프로그래밍 언어(C, C++, Lisp)까지 아우르는 정교한 소프트웨어 스위트로의 확장을 제안합니다.

## User Review Required

> [!IMPORTANT]
> **표준 규격 정의**: 모든 언어 구현체는 동일한 입력 인자(게임 수, 고정수, 제외수)와 출력 형식을 따라야 합니다.
> **빌드 시스템**: `make`를 사용하여 모든 언어의 소스 코드를 한 번에 컴파일하고 바이너리화하는 환경을 구축합니다.
> **환경 확인**: 시스템에 `cobc`, `gfortran`, `gcc`, `g++`가 모두 설치되어 있음을 확인했습니다.

## Proposed Changes

### [Architecture] PolyLotto 프로젝트 구조 설계

#### [NEW] 디렉토리 구조 최적화
1.  **`src/`**: 모든 소스 코드를 언어별 폴더로 관리합니다.
    - `src/lisp/`: 현재 핵심 로직을 모듈화하여 저장.
    - `src/c/`: 고성능 난수 생성 및 커널 엔진.
    - `src/cpp/`: 객체지향 기반의 유연한 비즈니스 로직.
    - `src/cobol/`: 고전적인 데이터 처리 및 결과 보고서 생성.
    - `src/fortran/`: 복잡한 통계 분석 및 확률 계산 최적화.
2.  **`bin/`**: 컴파일된 실행 파일들이 저장되는 경로.
3.  **`include/`**: C/C++ 공유 헤더 파일.
4.  **`Makefile`**: 전체 프로젝트를 관장하는 통합 빌드 스크립트.

### [Implementation] 단계별 개발 로드맵

#### PHASE 1: 기초 구조 공사 및 Lisp 모듈화
- 기존 `lotto.lisp`를 `src/lisp/lotto.lisp`로 이동하고, 재사용 가능한 모듈 구조로 개편.
- 프로젝트 루트에 통합 `Makefile` 작성.

#### PHASE 2: C & C++ 엔진 구축 (`src/c`, `src/cpp`)
- **C**: 난수 생성 및 성능 위주의 기본 엔진 구현.
- **C++**: 클래스 기반으로 고정수/제외수 필터링 시스템 구현.

#### PHASE 3: 레거시의 귀환 (`src/cobol`, `src/fortran`)
- **COBOL**: 70년대 비즈니스 스타일의 정교한 결과 출력 리포트 구현.
- **FORTRAN**: 과학적 난수 생성 및 기초 통계 기능을 갖춘 엔진 구현.

#### PHASE 4: 통합 오케스트레이터 개발
- 어떤 언어 버전의 로또 프로그램을 실행할지 선택할 수 있는 통합 프론트엔드 스크립트(또는 Lisp 래퍼) 개발.

## Verification Plan

### Automated Tests
- `make all`: 모든 언어의 바이너리 빌드 확인.
- `make test`: 각 언어별 시뮬레이션 결과가 통계적으로 일관성 있는지 확인.

### Manual Verification
- 각 언어별 실행 파일(`bin/lotto-c`, `bin/lotto-cobol` 등)이 동일한 인자값에 대해 올바르게 동작하는지 확인.
